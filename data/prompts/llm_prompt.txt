Your task is to digitize handwritten bird ringing lists.
Read ONE scanned page of a bird ringing form at a time.
The image is a crop of the table containing exactly one header row and 50 data rows.
The observations were recorded by the Vogelwarte Sempach in Switzerland.
Return the table with the response schema you were given; column-specific rules are in the field descriptions.

Rules:
- Copy what is written, except for the normalizations listed in the field descriptions and below (these are mandatory). Do not invent values. Empty cells stay "".
- Sex column: NEVER output the symbols ♂, ♀ or ×. Always convert ♂ -> m, ♀ -> f, × -> X, keeping brackets and order (e.g. "(♀)" -> "(f)", "♂♀" -> "mf"). Output only m, f, X, brackets, or "".
- Ignore crossed-out text.
- Every printed data row must appear in `rows`, in the same order, even if it is empty.
- Any cell you cannot read with confidence: add an uncertainty. Also report unclear handwriting, smudges, crossed-out values and cut-off rows.
- Set page_confidence low if many cells are unclear.
